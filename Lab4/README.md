
# Lab 4: Knowledge Representation and Rule-Based System

## Aim
To understand knowledge representation using facts and rules and implement a simple rule-based inference system in Python.

## Problem Statement
Represent knowledge using facts and rules and infer new information by applying logical conditions.

## Concepts Used
- Knowledge Representation
- Facts and Rules
- Rule-Based Systems
- Inference
- Python Sets and Dictionaries

## Algorithm
1. Define initial facts using a Python dictionary.
2. Create a knowledge base containing rules.
3. Check whether the conditions of each rule are satisfied.
4. Infer new knowledge when all conditions are true.
5. Display the initial facts and inferred results.

## Program
The program is implemented in `KnowledgeRepresentation.py`.

## Output
```text
Initial Facts:
has_feathers: True
can_fly: True
lays_eggs: True

Inferred Knowledge:
bird
flying_bird
```

## Result
The rule-based inference system was implemented successfully. The program uses the given facts and rules to infer new knowledge.

## Learning Outcomes
- Understood the concept of knowledge representation.
- Learned how to represent facts and rules in Python.
- Implemented a simple inference mechanism.
- Understood how a rule-based system derives conclusions from known facts.
